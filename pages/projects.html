II. Software and Data

Metadata Extraction and FAIR Packaging Pipeline

January - June 2026LAGE, Area Science Park
MIT license

A modular Python pipeline. It extracts and packages sequencing metadata from instrument-native files into standardised JSON and FAIR RO-Crate research objects.

  • A two-pass scan identifies data types and links raw files to laboratory instruments and activities.
  • A registry-pattern design detects file types from their internal content, not their filenames.
  • A common top-level JSON schema with five common fields, aligned with the DECOS institutional Common Data Model.
  • A sample history module traces provenance across files, sequencing targets and platforms.
  • RO-Crate 1.2 packaging in JSON-LD, validated with the RO-Crate Playground.

Document Text Extraction and Embedding API

November 2025 - March 2026Area Science Park
Personal project

A FastAPI service that extracts and vectorizes text from JSON, plain text and PDF files, for search and semantic similarity.

  • Header-based PDF chunking, with transformer embeddings (E5-base), batch processing and mean pooling.
  • Payload size limit (15 MB), request logging and rotating log files.
  • Automated deployment to a Linux virtual machine with GitHub Actions and systemd.
